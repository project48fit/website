# Project Reporting

## Purpose
Generate concise weekly reporting tied to booked calls per week and send to coach@projectfitness.co.

## Inputs
- Week range
- Apply submissions
- Booking clicks
- Booked calls
- Notable changes or experiments

## Outputs
- Short report with metrics and brief insights
- Email-ready format

## Procedure
1) Summarize the week range and North Star metric.
2) List counts for apply submissions, booking clicks, booked calls.
3) Note changes that might affect results.
4) Provide one to three next actions.
5) Keep the report under 200 words.

## Failure Modes and Red Flags
- Missing booked calls metric
- Unclear timeframe
- Long narrative without actions

## Examples
Good:
- "Booked calls per week: 6. Apply submissions: 21. Booking clicks: 14."
- "Next: tighten Apply hero copy and add clarity on training cadence."

Bad:
- "We crushed it this week, huge growth"
- "Traffic increased, no data on calls"
