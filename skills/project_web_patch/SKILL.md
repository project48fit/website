# Project Web Patch

## Purpose
Apply small, safe edits to the allowed website surfaces while protecting brand and conversion flow.

## Inputs
- Page or component targets
- Specific text or section changes
- Guardrails from docs

## Outputs
- Updated file content
- Short summary of changes and locations

## Procedure
1) Identify the correct file for the target surface.
2) Make minimal edits that keep routing and layout intact.
3) Keep the copy concise and executive focused.
4) Confirm the service is clearly fitness coaching.
5) Confirm no pricing changes.
6) Ensure no em dash characters.
7) Provide final output in full file content format.

## Failure Modes and Red Flags
- Changing pricing or adding discounts
- Editing API routes or env usage
- Adding scarcity or hype language
- Introducing SaaS tone or generic AI filler
- Breaking headings or button semantics

## Examples
Good:
- "Strength training and nutrition coaching built for founders."
- "Request Private Coaching"

Bad:
- "Limited slots, apply now"
- "Unlock your growth with our platform"
